# STOCK-PRICES-ANALYSIS
This project applies data analytics to stock price data, transforming raw information into insights. It highlights skills in data cleaning, feature engineering, and visualization. The analysis reveals trading concentration among major companies and shows how market performance and trends vary over time.
This project was completed as part of my remote internship, where I worked on analyzing real-world stock market data and building machine learning models to better understand price behavior and short-term trends.
Project Objectives:
Understand stock price behavior using historical data
Identify trends and relationships between key financial variables
Apply data analysis and visualization techniques
Build and evaluate machine learning models for price prediction
Exploratory Data Analysis
I explored the dataset to understand how stock prices behave over time.
This included:
Analyzing price distributions
Comparing trading volumes
Studying relationships between open, close, high, and low prices
I also used visualizations to make patterns easier to understand.
Trend Analysis
To better capture market behavior, I applied moving averages (50-day and 200-day) to highlight both short-term fluctuations and long-term trends.
Feature Relationships
I performed correlation analysis to understand how different variables are related and how they influence each other.
Clustering
I grouped stocks based on similar characteristics such as price range and trading activity. This helped identify patterns across different types of stocks.
 Machine Learning Models
I built and compared several models to predict short-term price movements:
Logistic Regression
Decision Tree
Random Forest
This included:
Feature engineering
Data scaling
Train-test splitting
Model evaluation and tuning
Key Insights:
Opening price has a strong influence on closing price
Price-related features are highly correlated
Moving averages help reveal clear market trends
Trading volume varies significantly across stocks
Predicting stock prices is possible to an extent, but remains challenging due to market volatility
Tools & Technologies:Python,Pandas & NumPy,Matplotlib & Seaborn,Scikit-learn,Jupyter Notebook
